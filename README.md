# Mustard Bio — Brand

Brand source of truth for Mustard Bio, the intelligence layer for the pharmaceutical factories of the future.

- `brief/` — Comms and marketing brief (PDF + text).
- `logo/` — The chosen logo: SVG suite, construction sheets, 8K images and mockups.
- `docs/logo-reference.md` — Logo idea, exact geometry, file index.
- `source/` — `build_logo.py` + `kit.py` regenerate the logo from its geometry. Fonts: IBM Plex Sans / Mono (SIL OFL).

```
cd source && pip install -r requirements.txt && python build_logo.py
```
